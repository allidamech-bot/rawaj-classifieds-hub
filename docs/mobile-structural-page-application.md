# Mobile structural page application

Presentation-only pass for listing studio, listing detail, messaging, account surfaces, and trust/support pages.

- Bright layered surfaces replace dark hero blocks.
- Mobile listing studio trust cards use a two-column grid.
- Studio steps are denser on narrow screens.
- Listing media uses a lighter neutral stage and shorter mobile height.
- Account surfaces receive consistent mobile gutters and desktop max width.
- Messaging and trust/support heroes use the same bright structural language.

No data, authentication, permissions, the retired backend, API, publishing, messaging, moderation, or Android behavior is changed.
