# Owner Listing Command Page

Scope: `/profile/listings/:id` manage mode only.

Design intent:
- owner-focused command workspace, not a public listing page
- dark graphite surfaces with restrained warm-gold emphasis
- strong command hero and compact status context
- clear editing hierarchy
- gallery-like media management
- sticky desktop command rail for readiness, preview, quality and actions
- mobile-first collapse with preview/readiness before edit sections

Non-goals:
- no public listing redesign
- no My Store redesign
- no listing business-logic changes
- no backend or moderation changes
- no production deployment
