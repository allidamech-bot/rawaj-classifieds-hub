# رَوَاج | RAWAJ

سوق سوريا المجاني للإعلانات المبوبة — Web/PWA وتطبيق Android.

## البنية المعتمدة

رَوَاج يعمل على بنية واحدة واضحة:

- **Firebase Authentication** للتسجيل والدخول وGoogle واستعادة كلمة المرور والجلسات.
- **Cloudflare Worker** لجميع واجهات API والصلاحيات والإدارة.
- **Cloudflare D1** لجميع بيانات التطبيق.
- **Cloudflare R2** للصور والملفات والتسجيلات الصوتية ووثائق التحقق.

لا يوجد مزود بيانات بديل أو fallback في الواجهة. كل قراءة أو كتابة للتطبيق تمر عبر
Cloudflare Worker، وتُفرض الملكية والصلاحيات من الخادم.

## الوظائف الأساسية

- تصفح الأقسام والمناطق والإعلانات والبحث والفلاتر.
- التسجيل والدخول وإدارة الحساب والملف الشخصي.
- إنشاء الإعلانات وتعديلها ورفع الصور وإرسالها للمراجعة.
- المفضلة وعمليات البحث المحفوظة وسجل المشاهدة ومتابعة البائعين.
- المحادثات النصية والصور والتسجيلات الصوتية الخاصة.
- الإشعارات وتفضيلاتها وتسجيل أجهزة Push.
- التقييمات والبلاغات والدعم وطلبات التحقق.
- دورة حياة الإعلان والحجز وانتهاء الصلاحية والترويج.
- لوحات الإدارة والمراجعة والسلامة وجودة البيانات والتحكم التشغيلي.

## التقنية

- TanStack Start + React 19 + Vite 8
- TanStack Router
- TypeScript strict
- Tailwind CSS v4 + Radix UI
- Firebase Authentication
- Cloudflare Worker + D1 + R2
- Capacitor Android

## التشغيل المحلي

```bash
npm ci
npm run dev
```

الواجهة المحلية الافتراضية تعمل عبر Vite، والـWorker المحلي عبر أوامر مجلد
`cloudflare/worker` وفق ملف الإعداد المولّد محليًا.

## بوابة التحقق

```bash
npm run check:cloudflare
```

تشمل البوابة:

1. منع أي عودة للـbackend المتقاعد داخل Runtime أو الإعدادات التشغيلية.
2. اختبارات عقود Cloudflare والصلاحيات.
3. إعادة تشغيل جميع D1 migrations من الصفر.
4. TypeScript للتطبيق والـWorker.
5. بناء الإنتاج.

لا تنفذ بوابة التحقق أي نشر أو migration بعيدة.

## المسارات الرئيسية

| `/` | الرئيسية والاكتشاف |

## قيود النشر

- لا تُشغّل migrations البعيدة ضمن أمر النشر.
- لا تغيّر Production أو traffic أو bindings دون مراجعة وموافقة صريحة.
- لا تُدخل أسرارًا في ملفات الواجهة أو Git أو السجلات.
